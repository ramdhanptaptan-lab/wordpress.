== Description ==

Furniture Carpenter Lite is a clean and easy-to-use WordPress theme designed for carpenters, furniture makers, woodworkers, cabinet manufacturers, interior designers, and home renovation businesses. It features a modern, responsive layout that looks great on all devices and helps you showcase your craftsmanship professionally. The theme includes customizable sections for services, projects, testimonials, and contact details, making it simple to create a business website without any coding knowledge. Built with SEO-friendly code and optimized for fast loading, it helps improve your website's performance and online visibility. Furniture Carpenter Lite is compatible with popular WordPress plugins and offers a user-friendly customization experience through the WordPress Customizer. Whether you're promoting custom furniture, woodworking services, or interior solutions, this free theme provides everything you need to establish a professional online presence and connect with potential customers.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click the Add New button.
2. Click Upload Theme and Choose File, then select the theme's .zip file. Click Install Now.
3. Click Activate to use your new theme right away.
